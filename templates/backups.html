Backups 数据备份

Everything — the accounts, ledger, payroll, suppliers and every scanned document — lives in one database on one server. These are the copies that get it back.
⚠️ The snapshots below sit on the same disk as the live system. They protect against a bad update or data being deleted by mistake — they do not protect against that disk failing.
Download the full backup below and keep it somewhere else (your computer, Google Drive) — do that regularly, and definitely before anything major.

If you ever need to restore 恢复方法

Every download contains a README.txt with the steps. In short: the database file goes back to the path in DATABASE_URL, the uploads folder goes back to UPLOAD_DIR, then restart the app. Ask before doing this on the live system — restoring replaces whatever is currently there.
