Connect Karen's request form 连接申请表

{{ icon('list', 14) }} Purchase Requests
Once connected, every request Karen fills in her Google form arrives here as a Purchase Request (KR-yymm-nnn), ready to put on an approval list. One-time setup, about two minutes.

Steps

  1. Open Karen's form spreadsheet (CatDay | Purchase & Expense Requests).
  2. Menu Extensions → Apps Script. Delete what's there and paste the script below. Click Save.
  3. In the function drop-down choose install, click Run, and approve the permission prompt (it asks to read the spreadsheet and connect to an external service — that's this system).
  4. Back in the sheet you'll see “Connected”. New and edited requests now arrive every 5 minutes, or straight away from the sheet menu CatDay → Send requests to finance now.
Each new month's copy of the form needs the same paste + install once. The script contains a private key for this system — don't share it outside the company.
